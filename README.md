# Удивительный космос
## Познавательная интерактивная игра с космическим атласом

Ребёнок отправляется в исследовательскую экспедицию вместе с дружелюбным роботом **Астро**.

Игроку предстоит познакомиться с необычными объектами Вселенной, научиться узнавать их по характерным признакам, выполнять проверочные задания и постепенно собрать собственный космический атлас.

Игра объединяет научно-популярные сведения, задания на понимание прочитанного и элементы игровой мотивации.

Каждое успешно завершённое исследование открывает новую страницу атласа с изображением космического объекта, интересным фактом и ссылкой на научный источник.

## Особенности игры

- Исследовательская экспедиция с роботом Астро.
- Знакомство с необычными объектами Вселенной.
- Распознавание космических объектов по характерным признакам.
- Проверочные задания на понимание прочитанного.
- Постепенное пополнение собственного космического атласа.
- Изображения, интересные факты и ссылки на научные источники.
